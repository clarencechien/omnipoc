- 探 API schema 只送無效值，永遠不送合法 body（2026-11-07 xAI 意外 $0.70）。

- 每支影片過 `cropdetect`，ffprobe 看不出 letterbox。
- 估價 → ledger → 呼叫 → 落檔 → 下一筆；失敗 4xx 不計費但要記。

## 規則（婚禮 MV 新增）
- 參考圖必須先通過服裝與框臉檢查，才能拿去生影片。
- 影片穿幫：兩次都標出才算，落在要用的秒數內一律人工逐格確認。
- 先放大乾淨畫面，再加字幕與音樂；保留無字幕母帶。
- 所有輸出 `-pix_fmt yuv420p -profile:v high`，並用 ffprobe 確認。
